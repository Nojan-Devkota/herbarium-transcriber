# Herbarium Label Transcriber

Turns a photo of a pressed-plant herbarium sheet into a verified Darwin Core record.
SAM 3.1 finds every label, Muse Spark reads and interprets it, and a verification
agent checks the result against GBIF before a curator reviews it.

See [docs/design.md](docs/design.md) for the full design.
